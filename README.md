## 🚀 Featured projects

### 🔥 Pyroscope
Harmonizes **NASA FIRMS MODIS and VIIRS** active-fire data into one consistent view, with a country-by-country fire forecast map. Built for **NASA Space Apps Challenge (Cairo)**.

### 🖼️ AI Image Understanding & Content Matching Engine
Node.js backend where a vision model tags an image library, embeddings match images to blog posts, and a **"mismatch guard"** rejects bad pairings (a wolf photo on a fox article, say) with an explanation instead of guessing.

### 🧩 CPT: Children Physiological Therapist
Map-based therapeutic gaming platform for children with ADHD (focus, impulse control, working memory), plus a companion parent site. Piloted in public schools and recognized by medical professionals.

### 🌐 [GIUNet](https://github.com/mark1234720/GIUNet)
Custom **UDP chat protocol in Java** with a handshake, ACKs and retransmission, plus a Cisco Packet Tracer campus network simulation.

### 📈 More

- Page-performance ranking notebook comparing a hand-written scorer against a decision tree, evaluated with `precision@k`
- CO₂ emissions prediction with machine learning
- Java/JavaFX board game engine with animations and sound
